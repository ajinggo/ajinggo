## 正在做的作品

### 01 &nbsp; CostBuddy · 你的做 T 搭子

**买卖之后，离回本还有多远？**

为港股、A 股和美股持仓测算买卖后的资金回本成本，把价格、股数和手续费放在一起看清楚。

`回本成本测算` &nbsp; `加仓成本轨迹` &nbsp; `目标成本反推`

[打开 CostBuddy ↗](https://costbuddy.space) &nbsp; · &nbsp; [查看源码](https://github.com/ajinggo/costbuddy)

### 02 &nbsp; Credit Card Ledger · 信用卡账本

**让每张卡的账，心里都有数。**

集中整理信用卡额度、月度账单和还款进度，也记录手续费与积分。支持 Supabase 云同步和 JSON 备份。

`额度管理` &nbsp; `账单与还款` &nbsp; `云同步与备份`

[打开信用卡账本 ↗](https://credit-card-ledger.vercel.app) &nbsp; · &nbsp; [查看源码](https://github.com/ajinggo/credit-card-ledger)
