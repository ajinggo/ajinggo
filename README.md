## CostBuddy

港股、A 股和美股的持仓成本计算器。输入价格、股数和手续费，计算买卖后的回本成本，也可以按目标成本反推买入方案。

[使用](https://costbuddy.space) · [代码](https://github.com/ajinggo/costbuddy)

## 信用卡账本

记录信用卡额度、账单、还款、手续费和积分。支持 Supabase 同步和 JSON 备份。

[使用](https://credit-card-ledger.vercel.app) · [代码](https://github.com/ajinggo/credit-card-ledger)
